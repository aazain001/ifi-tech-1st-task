This framework provides a generic, repeatable blueprint pattern to onboard files, databases, or API streams into the Bronze staging environment:

-------------------------------------------------------------------
SECTION 1: FILE-BASED ONBOARDING METADATA TEMPLATE
-------------------------------------------------------------------
To ingest any raw flat files (CSV, Parquet, JSON), the data pipeline must ingest data based on this standard metadata structural schema mapping:

{
    "IngestionSourceType": "File-System",
    "SourceSystemName": "ERP_Sales_Blob",
    "SourceFilePath": "raw/landed_zone/incoming_transactions/",
    "SourceFileFormat": "CSV",
    "FileDelimiter": ",",
    "HeaderExists": true,
    "TargetLakehouse": "my_first_lake_house",
    "TargetBronzeTable": "bronze.dbo.raw_transactions",
    "IngestionMode": "Append",
    "WatermarkColumn": "TransactionDate"
}

-------------------------------------------------------------------
SECTION 2: CORE INGESTION PIPELINE & NOTEBOOK PATTERN
-------------------------------------------------------------------
Every pipeline onboarding data into the Bronze layer must execute using this standard operational template sequence:

1. COMPONENT A: INGESTION PIPELINE NODE
   - Action: Read variables from the Ingestion Metadata JSON configuration schema map.
   - Execution: Launch a Data Factory copy activity to sweep the incoming source path and stream raw blocks straight into storage without changing any column names or structures.

2. COMPONENT B: AUDIT NOTEBOOK CELL
   - Action: Programmatically intercept the landing data inside your PySpark script.
   - Execution: Append three mandatory system audit tracking fields to the dataset before finalizing the transaction:
     - df = df.withColumn("src_system_name", lit(metadata.SourceSystemName))
     - df = df.withColumn("ingestion_timestamp", current_timestamp())
     - df = df.withColumn("pipeline_run_id", lit(pipeline().RunId))

3. COMPONENT C: ACID COMPLIANT COMMIT
   - Action: Write raw dataframe blocks straight into the Delta format storage tier.
   - Execution: Use df.write.format("delta").mode("append").saveAsTable("bronze.dbo.[table_name]") to lock in historical audit immutability.
