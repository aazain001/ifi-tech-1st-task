1. NEW ENGINEER ONBOARDING WORKFLOW (NO BRIEFING REQUIRED)
-------------------------------------------------------------------------------
Welcome to the project. Follow these 4 steps to get your environment ready:

[ ] Step 1: Gain access to the Azure subscription and Microsoft Fabric tenant.
[ ] Step 2: Ensure your Microsoft Entra ID is mapped to the Data Engineer group.
[ ] Step 3: Clone this repository to your local development environment.
[ ] Step 4: Link your development workspace to the project Git repository.

-------------------------------------------------------------------------------
2. DEPLOYMENT PIPELINE RUNBOOK
-------------------------------------------------------------------------------
To deploy code changes from your local workspace up to production:

1. Feature Development:
   Create changes inside an isolated scratch workspace linked to a feature branch.
2. Pull Request:
   Commit your changes and open a PR into the main development branch. 
   Ensure your code passes the "Definition of Done" criteria.
3. Automated Promotion:
   Once the PR merges, deployment pipelines leverage fabric-cicd pipelines to
   automatically update targeted environments.

-------------------------------------------------------------------------------
3. TROUBLESHOOTING & DESIGN EXPECTATIONS
-------------------------------------------------------------------------------
* Notebook Standards: All PySpark code must incorporate parameterization blocks
  and standardized audit logging features.
* Schema Changes: Any alteration to a Silver or Gold tier model structure 
  requires a corresponding update to the central Data Dictionary template.
