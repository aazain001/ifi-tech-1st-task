3. L1 SUPPORT RUNBOOK (INCIDENT RESPONSE)
-------------------------------------------------------------------------------
PROBLEM A: Pipeline or Notebook Execution Failure
  Step 1: Open Fabric Monitor Hub and locate the failed Run ID.
  Step 2: Inspect error logs for timeout, schema drift, or access errors.
  Step 3: If failure is capacity-related, check if current CU usage is maxed.
  Step 4: Retry the job manually once capacity clears.

PROBLEM B: Semantic Model Refresh Fails
  Step 1: Verify upstream data sources (Bronze/Silver/Gold layers) are updated.
  Step 2: Check workspace permissions and gateway connectivity.
  Step 3: Use semantic-link-labs utilities to test model connectivity.
